# Treadmill program screenshots

Native screenshots from the standard debug build of runtime commit `bcbdf3352fb6e5a89fbb1f0efbef9811c8ed481e`, captured on Android 15/API 35 at 1920×1080. The demo program uses short blocks to show transitions and looping. These captures demonstrate the UI; they do not validate physical motor or firmware behaviour.
